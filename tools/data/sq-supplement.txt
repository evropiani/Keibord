# Format: <word> <zipf> [<spelling> ...]
#   zipf = log10 occurrences per billion words ("të" ~ 7.7, a rare word ~ 1.5). The word is added
#   with exactly this casing; if the corpus already has it, the higher zipf wins.
#   Optional spellings (lookup keys) are absorbed: they are removed from the dictionary so the
#   keyboard corrects them to the word (accent restoration for "kosove" -> "Kosovë").
# The OpenSubtitles corpus has few place names; these values are hand-tuned estimates.
# Reference corpus values: Amerikë 4.53, Francë 4.22, Gjermani 4.02, Shqipëri 3.20.
