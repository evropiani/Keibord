# English contractions for tools/build_dictionaries.py.
#
# The OpenSubtitles word counts (FrequencyWords) split "don't" into the tokens "don" and "'t",
# so the builder reconstructs a count for every contraction listed here:
#
#   <contraction> stem          count = count of the stem token (the part before the apostrophe),
#                               which only occurs as part of this contraction ("didn", "isn", ...)
#   <contraction> share <w>     count = w x (count of the suffix token ("'t", "'s", ...) minus the
#                               counts already taken by "stem" lines with the same suffix)
#
# Afterwards each contraction's count is subtracted from its stem token ("i", "let", "can", ...),
# so "let" is not inflated by "let's". Weights are rough shares of the suffix in conversational
# English; "'s" keeps ~20 % for possessives. A contraction that the variant's Hunspell rejects is
# not added to that dictionary.
