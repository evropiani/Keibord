Keibord 1.0.32: dropping a dragged sticker into Messages.

- In 1.0.31 a dragged sticker could not be dropped: Messages takes a drop either as an attachment or as text, and the sticker looked like neither. It now also carries the rich text formats, so Messages takes it as text with the sticker in it, like when you paste it, but still without the folder format that 1.0.30 sent. Copy and paste is unchanged.
- The app's keyboard log (Data › Keyboard Log) now notes which format the app you drop into asks for ("sticker drag: the app loads …"). If a sticker still arrives wrong, send me those lines.

Install `Keibord.ipa` with your signer (keep app groups for the app and the keyboards), SideStore with the Keibord source, or TestFlight (docs/INSTALL-NO-PC.md). Installing over an earlier version keeps your data.
