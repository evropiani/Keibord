First release of Keibord, a private on-device keyboard.

- German (Austria) QWERTZ, English UK/US, Albanian (Albania/Kosovo) QWERTZ, Italian, all at once with multilingual autocorrect
- Autocorrect, accent restoration, predictions, learning, adaptive touch model
- Export/import of all typing data (optionally password-encrypted)
- iOS look with themes, custom colours and permanently tinted keys
- Emoji with search (de/en/it/sq), skin tones and recents
- Local AutoFill for your details and encrypted cards (CVV never stored)

Install `Keibord.ipa` with Sideloadly/AltStore/SideStore. See the README for step-by-step instructions.
