Keibord 1.0.9: export your settings.

- Data → Export now has three switches: Typing Data, All Settings, and My Details & Text Replacements. Export any combination – for example only your settings (languages, layouts, appearance, colours, tinted keys and every option) to set up another iPhone the same way.
- An import only changes what the file contains and tells you what that is: a settings file never touches what Keibord has learned, and a typing-data file keeps your settings.

Install `Keibord.ipa` with your signer (keep app groups for the app and the keyboard), SideStore with the Keibord source, or TestFlight (docs/INSTALL-NO-PC.md). Installing over an earlier version keeps your data.
