Keibord 1.0.17: the keyboard is back to how it worked in 1.0.10.

- The keyboard itself (keys, height, layout, how it loads and saves) is reset to version 1.0.10. Everything added to the keyboard since (height experiments, self-checks, keyboard log) is removed.
- The app keeps its improvements: export/import of everything, and the file picker that works on iOS 27.

Install `Keibord.ipa` with your signer (keep app groups for the app and the keyboard), SideStore with the Keibord source, or TestFlight (docs/INSTALL-NO-PC.md). Installing over an earlier version keeps your data.
